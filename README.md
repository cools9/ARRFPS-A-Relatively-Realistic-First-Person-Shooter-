## Objective

Your mission is simple: eliminate all **6 enemies** (represented by capsules) using your **AK-47**. Once all enemies have been defeated, you win the game.

If you have trouble locating an enemy, you can press **T** to teleport directly to its location. However, this is intended as a debugging/convenience feature and is basically cheating, so try to find them on your own first!

## Gameplay Notes

* Enemies are defeated with a single bullet.
* The game uses one-shot eliminations for fast-paced gameplay.
* Use the grappling hook to quickly traverse the map and reach difficult locations.

## Controls

| Key                          | Action                                     |
| ---------------------------- | ------------------------------------------ |
| **W, A, S, D**               | Move                                       |
| **Space**                    | Jump                                       |
| **Left Mouse Button (Hold)** | Shoot                                      |
| **Right Mouse Button**       | Use Grappling Hook                         |
| **T**                        | Teleport to the nearest enemy (Cheat Mode) |

### Grappling Hook Tip

For a quick boost into the air, look down at your feet and press **Right Click**. The grappling hook can launch you upward and help you reach higher areas.
